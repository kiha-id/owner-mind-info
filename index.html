Owner Mind

Aplikasi internal untuk mencatat keputusan, aturan, dan ide bisnis owner.

Owner Mind menyimpan keputusan bisnis yang disampaikan owner melalui ChatGPT ke dalam catatan perusahaan, supaya keputusan itu bisa dicari kembali dan dipakai oleh aplikasi internal lain.

Penggunaan Google Drive

  • Jika owner melampirkan file sebagai dasar sebuah keputusan, Owner Mind menyimpan salinan file tersebut ke Google Drive milik akun owner, di folder khusus Owner Mind – Lampiran.
  • Owner Mind hanya dapat mengakses file yang dibuatnya sendiri. Owner Mind tidak dapat membaca file lain di Google Drive tersebut.

Siapa yang memakai

Aplikasi ini hanya dipakai secara internal oleh owner dan tim IT. Aplikasi ini tidak tersedia untuk umum.
