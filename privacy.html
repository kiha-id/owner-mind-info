Kebijakan Privasi Owner Mind

Berlaku sejak 12 November 2026

Owner Mind adalah aplikasi internal untuk mencatat keputusan, aturan, dan ide bisnis owner. Aplikasi ini hanya dipakai oleh owner dan tim IT, dan tidak tersedia untuk umum.

Data yang diakses dari Google

  • Owner Mind memakai izin Google Drive yang paling terbatas (drive.file). Dengan izin ini, Owner Mind hanya dapat membuat dan mengelola file serta folder yang dibuatnya sendiri.
  • Owner Mind tidak dapat melihat, membaca, atau mengubah file lain di Google Drive pemilik akun.
  • Owner Mind tidak mengakses email, kontak, kalender, atau data Google lain.

Cara data digunakan dan disimpan

  • File yang dilampirkan owner sebagai dasar sebuah keputusan diunggah ke folder Owner Mind – Lampiran di Google Drive milik akun owner.
  • Owner Mind menyimpan nama file dan tautan Google Drive-nya di catatan keputusan internal perusahaan, supaya file itu bisa ditemukan kembali.
  • Salinan sementara di server Owner Mind dihapus setelah file berhasil diunggah ke Google Drive.

Berbagi data

  • Data tidak dijual dan tidak dibagikan kepada pihak ketiga.
  • Data tidak dipakai untuk iklan atau untuk melatih model AI.
  • Penggunaan dan pemindahan informasi yang diterima dari Google API mengikuti Google API Services User Data Policy, termasuk persyaratan Limited Use.

Mencabut akses dan menghapus data

  • Pemilik akun dapat mencabut akses Owner Mind kapan saja melalui pengaturan akses pihak ketiga di Akun Google.
  • File di folder Owner Mind – Lampiran dapat dihapus langsung oleh pemilik akun dari Google Drive.

Summary (English). Owner Mind is an internal tool used only by the owner and the IT team. It uses the Google Drive drive.file scope, so it can access only the files and folders it creates. Files the owner attaches to a decision are stored in the owner's own Google Drive (folder "Owner Mind – Lampiran"). Data is never sold, shared with third parties, used for advertising, or used to train AI models. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions. Contact: luckyformalities@gmail.com.
